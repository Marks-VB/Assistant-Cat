# Prompts dos seis ícones de aplicativo

Prompts fornecidos pelo usuário e utilizados como direção para a coleção. Os cinco temas adicionais usam o ícone Default como referência de identidade. A versão final Dark foi refinada para monocromia; o estudo com olhos coloridos foi preservado em `artes/estudos/`.

## 1. Default

```text
Modern mobile app icon, iOS squircle shape, centered front portrait of a sleek stylish cat face. Minimalist vector illustration style, clean bold outlines, vibrant yet balanced pastel-neutral color palette, smooth subtle gradient background. Professional digital product branding, crisp edges, high contrast, minimalist UI graphic design, 8k resolution, flat 2D vector logo.
```

## 2. Cyberpunk / Neon

```text
Cyberpunk futuristic mobile app icon, iOS squircle shape, centered head profile of a cybernetic cat. Glowing cyan and magenta neon accents, high-tech holographic eye visor, dark carbon-fiber matte background, subtle digital glitch details, sleek sci-fi aesthetic, sharp vector lines, premium dark UI icon.
```

## 3. Dark Mode / Pitch Black

```text
Stealth dark mode mobile app icon, iOS squircle shape, minimalist silhouette of a cat face. Solid pitch-black matte background, ultra-clean pure white and deep charcoal line art, minimal geometric details, luxury minimalist aesthetic, sharp contrast, modern typography and app logo feel.
```

## 4. All-White / Clean Ceramic

```text
Clean minimalist white-out mobile app icon, iOS squircle shape, centered stylized cat face portrait. Pure off-white and soft light gray palette, subtle smooth embossing and soft drop shadow, modern tactile ceramic texture, clean scandinavian design, elegant light theme app icon.
```

## 5. Anime Dark / Neo-Tokyo

```text
Stylized anime dark aesthetic mobile app icon, iOS squircle shape, badass anime cat with piercing glowing amber eyes. Sleek black tactical collar, sharp ink outlines, midnight purple and matte black background with subtle geometric accents, graphic novel vector style, dynamic and cool.
```

## 6. Golden / Premium Edition

```text
Exclusive VIP mobile app icon, iOS squircle shape, elegant minimalist cat face icon rendered with a polished satin gold metallic outline and accents, deep obsidian black background, subtle luxurious specular lighting, clean modern fintech app badge aesthetic.
```

Os ícones entregues são PNG de 1254 × 1254 px. “8k” faz parte do prompt original e não descreve a resolução dos arquivos gerados. O termo Premium é apenas o nome do tema visual.
