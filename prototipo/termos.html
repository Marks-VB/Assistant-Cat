Termos de Uso (protótipo)

Última atualização: outubro de 2026.

1. O que é

O Assistente Gato é um protótipo local e de código aberto para organização pessoal. Não há conta, assinatura nem pagamento.

2. Seus dados

Os dados ficam no seu navegador (IndexedDB/localStorage). Exportar e importar backups é responsabilidade sua. Veja a Política de Privacidade.

3. Uso aceitável

Não utilize o protótipo para atividades ilegais nem para processar dados sensíveis de terceiros sem base legal.

4. Sem garantias

Fornecido "como está", sem garantias. Faça backups regulares (menu Eu → Dados).
